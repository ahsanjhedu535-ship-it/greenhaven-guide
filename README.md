# GreenHaven Guide

Premium gardening guide starter built with Next.js App Router, JavaScript and CSS.

## Run locally
1. Install Node.js 18.17+.
2. Extract this folder.
3. Open a terminal in the folder and run `npm install`.
4. Run `npm run dev` and open `http://localhost:3000`.
5. Run `npm run build` to create the static site in `out/`.

## Deploy to Vercel
Import the Git repository or upload the project using a supported workflow. Framework preset: Next.js. Build command: `npm run build`. The project uses static export, so generated pages are in `out/`.

## Included
- Responsive premium homepage and category cards
- Search across the included gardening guides
- Six original starter articles
- About, Contact, Privacy and Disclaimer pages
- Generated visual assets in `public/images`
- SEO metadata and static article routes

## Important before launch
The contact form is front-end only and does not send messages. Connect a form backend before advertising a working contact form. Review all policy pages to reflect the actual services you use. Gardening content is general information and should be reviewed for your target region. AI-generated imagery may still need a platform/terms review; keep the original generated files and records.
